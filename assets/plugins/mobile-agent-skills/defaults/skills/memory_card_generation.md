# 记忆卡片生成

当用户要求把知识库条目、笔记或当前对话内容制作成记忆卡片时使用本 Skill。

## 适用场景

- “把知识库里的 XX 做成卡片/记忆卡片/复习卡/问答卡/抽认卡”。
- “用这些内容出题考我”。
- 用户希望背诵、复习或间隔重复某个知识点。

## 原则

- 一张卡片只承载一个原子知识点。
- 正面是问题、提示或挖空；反面是答案、解释或完整定义。
- 答案必须来自原文或可验证推导，不编造；信息不足时宁少勿多。
- 保留 Markdown 与 LaTeX；不要引用用户没有提供的来源。
- 用户指定牌组时写入该牌组；指定新牌组名时创建；未指定时写入默认牌组。
- 目标牌组或卡片数量不明确时，用 `ask_user` 追问。

## 调用流程

```text
1. 确定范围：哪个知识库/类别/哪些条目/多少张卡片
2. 读取原文：
   ├── 明确引用知识条目 → read_knowledge_entry(id)
   ├── 明确引用知识库   → read_knowledge_base(id)
   └── 模糊范围         → knowledge_search 查找后再读
3. 调用 create_memory_cards 批量创建
4. 返回牌组、创建数量与来源条目摘要
```

## 工具调用示例

`knowledge_search` 查找相关条目：

```json
{
  "name": "knowledge_search",
  "arguments": {
    "query": "<主题关键词>",
    "knowledgeBaseId": "<可选知识库 id>"
  }
}
```

`create_memory_cards` 创建卡片：

```json
{
  "name": "create_memory_cards",
  "arguments": {
    "deckId": "<目标牌组 id，未指定可省略写入默认牌组>",
    "cards": [
      {
        "front": "<问题或挖空>",
        "back": "<答案或解释>",
        "hint": "<可选提示>",
        "sourceEntryId": "<来源知识条目 id>"
      }
    ]
  }
}
```

## 质量门槛

- 不要为标题本身制作无意义卡片（如正面“什么是 X”，反面只写“X”）。
- 不要拆出重复卡片；正面相同但反面不同时合并或改写正面。
- 挖空使用 `{{c1::答案}}` 风格时，确保一张卡片只挖一个空。
- 数学公式使用 LaTeX：行内 `$...$`，块级 `$$...$$`。

## 返回约定

- 创建成功后只返回牌组名、创建数量与来源条目摘要。
- 不要向用户展示工具 JSON 原文。
- 创建失败时说明失败原因和已确认的下一步。
