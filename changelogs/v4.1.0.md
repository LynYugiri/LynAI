## v4.1.0 - 2026-09-22

### 新增
- **本机工作区**：支持挂载本地文件夹、按工作区隔离对话历史，并提供 Agent 工作区文件工具与对话页工作区抽屉
- **持久记忆与记忆卡片**：新增角色隔离的持久记忆、`memory` 工具、后台 review 与维护提醒、跨会话搜索和精确编辑；记忆卡片升级间隔重复调度，并支持从知识库按条目生成卡片
- **随记**：本地时间线记录，支持 Markdown 正文、附件、引用卡片、内联标签编辑和 Agent 搜索工具
- **定时任务**：按时间运行插件 Lua 脚本，支持每天/每周重复规则、运行历史、失败退避和连续失败自动停用
- **插件工坊**：宽屏两栏布局、能力可视化编辑、恢复点与就地运行/预览；对话内打通「生成草稿 → 静态校验 → 就地试跑 → 迭代」闭环
- **插件能力增强**：插件可选依赖声明、按配置注册工具与系统提示词、内置插件创作 Skill 集
- **命令面板**：对话页支持带类型化引用的命令面板与统一权限
- **知识库扩展**：新增内置专有名词库、库/类别/条目的自定义排序与 Agent 知识检索工具
- **新手向导**：欢迎页与引导流程，AI 生成角色、记忆、Agent 默认值、知识库、牌组、任务、笔记与 SKILL，并支持修改用户名和账号详情页
- **社区与市场**：完善帖子、评论、点赞、收藏与个人主页体验，支持分享插件卡片并跳转插件详情，市场展示上传者名称
- **数据同步**：新增选择性云同步与 LAN 同步、云数据管理、重新播种和安全多设备同步
- **本地模型**：Android 接入 BlueLM 3B（MediaTek DX5/MT6993，arm64）
- **设置与界面**：分组设置入口与设置项搜索、个人仪表盘（原状态插件升级）、内置每日总结插件、对话消息操作移到气泡下方并支持撤回撤销与分支

### 不兼容变更
- Agent 默认上下文窗口从 32k 提升到 256k
- 对话默认授予全权限，插件安装后单独弹出授权确认

### 优化
- Agent 上下文裁剪改为增量估算，并收敛重复的裁剪与提示块实现
- 收敛 storage_v2 原子写入、roleplay JSON 行解析、表名清单与参数转发样板
- 清理死分支、死默认值与零调用的公开 API，移除默认路径上的恒等分支与重复计算
- 出站 HTTP 客户端补全 TLS 握手，并在多个解析地址间回退
- 测试环境抽取路径、同步与内存仓库辅助工具，减少真实存储副作用

### 修复
- 修复 Markdown 表格列宽不随内容排布的问题，超宽表格改为横向滚动
- 修复日程页默认视图、上滑全收起和 Ctrl/滚轮缩放
- 修复编辑消息弹窗标题多余的「从此处开始新对话」后缀
- 修复附件 token 估算偏高，并支持关闭上下文压缩截断
- 修复工作区工具不可派发、知识库拖拽二次归一化等 Agent 派发与知识页交互问题
- 修复登出后 LynAI 托管模型被清空、无法未登录使用的问题
- 修复随记重命名标签时产生重复标签的问题
- 修复工具派发中未等待 `save_jotting`、`plugin_file_list` 等 Future 的问题
- 修复记忆工具可读取已删除角色记忆并重复加载的问题
- 修复本地模型 BlueLM SDK 的 JNI 回调符号被裁剪的问题
