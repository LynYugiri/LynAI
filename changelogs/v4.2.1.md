## v4.2.1 - 2026-09-26

### 新增
- **鸿蒙（HarmonyOS）适配**：新增 `ohos/` Stage 模型工程与 `lynai/` 系列原生插件，支持对话、Markdown/LaTeX/Mermaid、知识库、笔记、日程（系统后台代理提醒 + 2×2 / 2×4 服务卡片）、备份与云同步、局域网同步（手动配对码）、长图导出到图库、图片选择与拍照、选择文件与另存为、系统扫码、复制图片到剪贴板、分享、打开链接、应用内 WebView、语音输入（Core Speech Kit 离线识别）与生成期间的后台长时任务；构建、签名与首轮真机清单见 `doc/harmonyos.md`。
- **模型目录（models.dev）**：新增模型目录服务与设置页，自动补全上下文窗口、输出上限、视觉/工具/思考能力。数据来源优先级为后端 `/models/catalog` 代理 → 直连 models.dev（`If-None-Match`/304）→ 本地缓存 → 内置快照（25 provider / 1201 模型）；支持「从 Endpoint 获取模型列表」后顺带匹配、「按模型目录补全参数」批量补全、手动指定目录来源、清除本地缓存。目录只是补全建议：用户手填值与显式开关优先，缓存属于派生数据，不进入 storage_v2、备份、云同步或 LAN 同步。
- **思考强度**：输入栏思考开关右侧可按模型目录给出的取值选择强度（`minimal`/`low`/`medium`/`high`/`xhigh`/`max`），模型编辑弹窗可设模型默认强度；`none` 表示关闭思考。OpenAI 兼容写 `reasoning_effort`（OpenRouter 写 `reasoning.effort`），Anthropic 换算成 `thinking.budget_tokens`，Ollama 映射成 `think` 档位；托管 relay 只在后端广告 `capabilities.reasoningEffort` 时下发 `reasoning.effort`。
- **撤回提示倒计时**：撤回消息后的撤销提示条改成 10 秒环形倒计时（环 + 环心秒数 + 「撤销」），到点自动消失；插件权限提示 6 秒自动消失，错误提示保持常驻。

### 修复
- 修复切换对话时输入区浮层在 build 期间调用 `OverlayPortalController.show()/hide()` 触发的框架断言（Debug/Profile 下会直接报错并连带 `attached` 断言与「wrong build scope」）：浮层改为只显示一次、内容为空时不占位。
- 修复未创建对话时选择的思考强度不会被随后创建的对话保存、重开后又回到「默认」的问题。
- 修复输入区浮层未按可用高度夹取的问题：短屏/横屏下顶部（含返回行与首批候选）会被顶出屏幕且无法滚回来。
- 修复模型目录缓存并发写入可能写出损坏 JSON 的问题（刷新与手动登记来源会同时写同一文件），改为串行 + 先写临时文件再 rename；删除缓存时会先等在途写入结束。
- 修复模型目录刷新成功后仍显示上一次失败原因的问题（304 分支不会重建状态）。
- 修复手动指定的目录来源不在默认集合时无法解析的问题：登记后刷新会带上该 provider，并在有额外来源时通过 `?providers=` 传给后端代理；缓存文件跨进程保留这些来源。
- 修复模型编辑页在目录数据还没有该 provider 时的下拉框断言崩溃（`DropdownButton` 要求取值恰好命中一个选项）。
- 修复能力开关的显式选择会丢失的问题：只有用户真正拨动过的开关才写回子模型字段并固定成 `capabilityOverrides`，目录还没有建议时同样固定，没拨动的继续跟随目录。
- 修复切换模型后残留的思考强度会被发给新模型的问题：目录给出了取值列表时只接受列表内的值，`none` 不受限制。
- 修复鸿蒙聊天页销毁时同步调用 `lynai/speech` 通道、在其它平台抛 `MissingPluginException` 的问题；语音桥接改为静态回调 + 派发给「正在识别」的实例，多聊天页共存时不再互相抢通道。
- 修复鸿蒙「另存为」在用户取消时被当成失败抛 `PlatformException` 的问题，现在与其它平台一致返回 `null`。
- 修复鸿蒙服务卡片永远显示「近期无日程」的问题：通道解出的 `Map` 必须先折算成普通对象，否则落盘是 `[{}]`、字段访问也读不到值。
- 修复角色扮演页在鸿蒙上按 Ctrl/Cmd+V 粘贴图片时因 `super_native_extensions` 无实现而抛异常的问题（与主对话页共用同一个能力开关）。
- 修复鸿蒙批量选择文件时，同一毫秒内的同名文件会互相覆盖的问题（缓存副本名加入批内序号）。

### 优化
- 模型目录使用 single-flight 刷新、7 天 TTL，失败保留旧数据并把原因写进状态，不向 UI 抛异常；设置页展示来源、数据时间、最近检查与最近错误。
- 子模型列表每行显示生效的上下文窗口/输出上限及其来源（手填、Endpoint、目录、Provider 或默认值），「默认 256k」不再悄无声息。
- 后端 `/models/catalog` 增加 1 分钟失败退避，并把「上游返回 200 但一个 provider 都没有」按失败处理，不再清空已有缓存；上游请求固定 HTTPS、禁用代理环境变量、禁止重定向。
- 鸿蒙侧选择器、投影折算等纯逻辑补充 Node 单元测试；通道契约测试新增「ArkTS 孤儿通道」反向检查。
