## v4.2.0 - 2026-09-23

### 新增
- **对话页输入框草稿**：正文片段、引用 Chip 与暂存附件按对话独立暂存，切换对话时自动搬运，重启进程后仍能恢复；未创建对话的草稿只留本机。草稿属于对话分区，随对话进入普通备份、云同步与 LAN 同步，删除对话时随快照进回收站并在恢复对话时写回。
- **对话页 `@` 引用**：`@` 或引用按钮在光标处触发引用选择器，可引用对话、笔记、知识库、任务和日程等数据源；邮箱、URL、`A/B` 等普通文本不会误触发。
- **对话页 `/` 指令**：`/` 触发指令面板，提供 `/压缩`（把较早历史压缩为上下文检查点，原文仍保留在对话里）与 `/总结`（只展示结果，不进入上下文）。
- **会话引用池**：发送带引用的消息时自动收录引用，模型可通过清单按需取用；引用池不进入模型上下文，为空时系统提示词不提及。
- **Agent 工具**：新增 `read_conversation` 与 `list_conversation_references`，配套 `conversations:read` 权限。

### 不兼容变更
- 输入框草稿的存储位置从本机 SharedPreferences 迁移到 storage_v2 对话分区（Drift schema 34 → 35，逻辑分区 `composer_drafts.json`）；未创建对话的草稿仍然只留本机。
- 云同步与 LAN 同步的固定白名单新增 `composer_drafts`，后端同步新增同一张表：新后端必须先于新客户端部署，旧后端会整批拒绝含该表的请求。

### 优化
- 草稿保存使用 400ms 防抖并随 `flushPendingSaves()` 落盘；内容未变的槽位保留原 `updatedAt`，不再每次输入都产生一条同步变更。
- 草稿附件在选中时导入 storage_v2 Resource（按内容哈希去重，发送时复用同一份 blob），草稿行只保存 Resource ID 与展示元数据，本机路径由 Resource 解析；文件缺失时显示占位而不是丢弃条目。
- 加载草稿只解析实际引用的 Resource，避免每次打开对话都遍历整张资源表。
- 引用池按 `type:scope:id` 去重，并在超出上限时淘汰最久未使用的条目。

### 修复
- 修复草稿保存可能清空其他对话草稿的问题：落盘改为合并语义（只覆盖本次提到的槽位、只删除显式声明的槽位），内存缓存处于部分状态（启动时对话加载提前返回，或草稿读取失败保留旧缓存）时，一次按键不再把没提到的草稿一并删掉并经同步扩散。
- 修复输入框草稿在云同步中实际不可用的问题：云 reseed 会因 `composer_drafts` 不在权威表集合内抛 `FormatException`，远端草稿变更会被判定为「不支持的远端同步表」，增量应用则静默丢弃草稿；三处一并修复后草稿可以真正双向同步，清除草稿的删除变更也能传播到其他设备。
- 修复远端删除对话后草稿行留成孤儿的问题：对话被远端删除时一并清掉它的草稿行与同槽位未上传的变更。
- 修复回收站写入失败时内存与磁盘分叉、以及对话已存在时从回收站恢复会静默丢掉草稿的问题。
- 修复 `/压缩` 的覆盖范围算错导致的历史丢失：摘要只包含最新用户消息之前的部分，但检查点按「API 消息条数」推算覆盖前缀，会把空 assistant 占位与摘要条数算进去，连当前提问及其回复一起标记为已覆盖，下一次请求就只剩摘要。现在按同一套过滤规则把上下文映射回原始消息 ID。
- 修复 `@` 引用面板丢失文件夹下钻：`note_page`、`knowledge_entry` 等分层引用不可达，「引用整个 X」也不会出现。文件夹行现在进入下一层，进入后首行是该层自带的范围引用，笔记页面源先列笔记再列分页，面板返回按钮逐级回退。
- 修复未授权的 `read_conversation` 仍被写进系统提示词的问题：提示词现在与工具注册使用同一个 `conversations:read` 判断，不再指引模型调用不存在的工具。
- 修复发送成功后草稿残留，导致已发送的暂存附件在切回对话时「复活」并可能被重复发送的问题。
- 修复备份导出的草稿附件写入本机绝对路径的问题，并补回 `resourceId`，恢复时仍可按 Resource 重新解析附件。
- 修复录入引用后对话 `updatedAt` 不刷新的问题，避免只改过引用池的对话带着过期时间戳参与同步与排序。
- 补齐 `read_conversation` / `list_conversation_references` 的派发前参数校验。
- 修正 `doc/protocol-v1.md` 中关于 `composer_drafts` 部署顺序的相反描述，并补齐该表的强制约束与云端索引归类。
- 输入框附件预览只在文件存在时可点开，远端草稿附件尚未下载完成时不会再打开不存在的图片。
- 修复 `@` 引用触发面板被压在输入框上的问题：面板原本放在输入区 `Stack` 里用 `bottom: 0` 锚定，会盖住输入框与按钮行；现在改为跟随输入区上沿浮在其上方，并限制宽屏下的最大宽度。
- 修复 Anthropic 接口自 v2.2.3 之后不可用的问题（三处）：请求体里的 `thinking` 不再默认发送（该字段会让服务端按扩展思考校验：模型需支持、temperature 必须为 1，不满足直接 400，所以此前普通对话也会失败）；`thinking` 现在由输入框的思考开关决定，开启时不再同时发 `temperature`；中转在 `message_stop` 之前直接断流时保留已收到的正文，不再把整次回复判为失败；`system` 段为分段内容时不再在客户端抛类型错误。
